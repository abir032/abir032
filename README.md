I build mobile applications end to end — from architecture and state management through to the last 4 points of padding. Most of my work lives in the Apple ecosystem with **SwiftUI** and **UIKit**, and I ship cross-platform with **React Native** when a shared codebase is the right call.

**How I work**

- **Architecture first** — MVVM / Clean layering, dependency injection, testable view models. Features should be addable without touching five unrelated files.
- **UI as a system** — reusable components, consistent spacing and type scales, no one-off styling. Dark mode and Dynamic Type from day one.
- **Performance is a feature** — smooth scrolling, no main-thread blocking, lazy loading, and an eye on memory and app size.
- **Ship, then refine** — pragmatic delivery over perfect abstractions, with refactors driven by real usage.
